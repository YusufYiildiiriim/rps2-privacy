# rps2 Gizlilik Politikası

rps2 oyununun gizlilik politikası sayfası. Tek dosya: `index.html` (Türkçe ve İngilizce bölümler).

## GitHub Pages ile yayın

1. Repoyu GitHub'a **public** olarak gönderin (ücretsiz planda private repodan Pages yayınlanamaz).
2. Repo sayfasında **Settings → Pages** bölümüne gidin.
3. **Build and deployment** altında **Source: Deploy from a branch** seçin.
4. **Branch: `main`**, klasör **`/ (root)`** seçip kaydedin.

`.nojekyll` dosyası, GitHub Pages'in Jekyll işlemesini kapatmak için vardır.

Repoya yalnızca politika metni ve iletişim bilgisi girer.
